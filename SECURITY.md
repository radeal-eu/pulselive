# Security policy

If you find a security problem in the Pulse Monitor Live API, or in the web client or examples in this repository,
please do **not** open a public issue. Write to **support@pulsemonitor.net** with a short description and, if you can,
the steps to reproduce it. Do not include real access keys or participant data.

We will answer as soon as we can.

The Live API is meant for a local network you control; see [Encryption and the certificate](README.md#encryption-and-the-certificate)
and the note about keeping the access key secret in the [README](README.md).
